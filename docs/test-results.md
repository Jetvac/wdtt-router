# Проверка на временных серверах

Дата: 3 октября 2026 года. Входной сервер — Lisette (`135.106.161.90`), выходной — Elvira (`139.100.232.172`). Cloudflare Mesh создавался только в отдельном тестовом Zero Trust аккаунте. Существующие узлы `wdtt-de` и `wdtt-msk` и их маршруты в основном аккаунте не изменялись.

| Проверка | Результат |
| --- | --- |
| Go tests, vet, форматирование, синтаксис установщика | Прошли; [CI для 0.1.0](https://github.com/Jetvac/wdtt-router/actions/runs/37126317803) завершился успешно. |
| GitHub Release | [0.1.0](https://github.com/Jetvac/wdtt-router/releases/tag/v0.1.0): установщик, SHA256SUMS, архивы Linux amd64 и arm64. |
| Установка и обновление панели | Lisette установлена через `install.sh`; обновление из опубликованного релиза проверило SHA-256, сохранило состояние и запустило службу. |
| WDTT | Сервис, `wdtt0`, адрес `10.66.66.1/24` и UDP-порты 56000/56001 проверены. Перезапуск через задание панели прошёл. |
| Mesh | Два тестовых узла здоровы по Cloudflare API; `/1` маршруты указывают на выходной узел, `10.66.66.0/24` — на входной. Контейнер на выходе намеренно останавливали: `selftest` обнаружил отказ; после запуска связность восстановилась. |
| Прямой выход, VLESS, WARP | Проверены TCP и UDP/DNS через отдельный тестовый namespace и прозрачный путь с `wdtt0`. Прямой выход показал IP Elvira; при WARP выход через VLESS показал `104.28.196.105`, UDP прошёл. Перезапуск 3x-ui не нарушил путь. |
| Firewall и откат | Режим stealth применён без потери SSH; независимый 180-секундный таймер восстановил доступ после намеренного неверного ограничения SSH. Откат выбранного снимка firewall и маршрутизации через панель прошёл; после отката оба узла прошли `selftest`. |
| Перезагрузка | Оба VPS перезагружались; WDTT, Mesh, маршруты, VLESS и 3x-ui восстановились и прошли самопроверку. |
| Секреты и диагностика | Сохранённые данные 3x-ui/VLESS доступны только после входа, диагностический файл без входа возвращает 401. Скачанный файл проверен на пароль панели, токен Cloudflare, VLESS-ссылку, приватный ключ и cookie — совпадений нет. |
| Веб-интерфейс | В Edge проверены вход, обзор, настройки маршрута/firewall, WARP, история и кнопки отката, мобильная навигация. Ошибок JavaScript и горизонтального переполнения нет. |

Проверка с настоящим клиентом PWDTT не проводилась: тестового клиентского устройства пока нет. Синтетические TCP/UDP проверки подтверждают путь между VPS, но не проверяют установку и подключение внешнего клиента. Архив arm64 собран CI, запуск на arm64 VPS не проверялся. Произвольная цепочка с промежуточными узлами сохраняется как желаемая схема, но автоматически ещё не применяется.
