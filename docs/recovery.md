# Диагностика и восстановление

## Проверки

```bash
sudo wdtt-router agent status | less        # состояние компонентов сервера
sudo wdtt-router agent probe                # на входе: TCP и UDP через всю цепочку
systemctl status wdtt-router wdtt-router-xray wdtt-router-wdtt x-ui warp-svc
warp-cli --accept-tos status                # Mesh
nft list table inet wdtt_router             # firewall
journalctl -u wdtt-router -f                # журнал панели
```

В панели: «Обзор» → «Проверить», «Задачи» (журнал каждой операции), «Безопасность».

## Типичные ситуации

**Панель потеряла связь с сервером после изменения firewall.** Ничего делать не нужно: через 2 минуты сервер сам вернёт прежние правила, а в статусе появится отметка об откате. Исправьте настройки и примените снова.

**Mesh на сервере не подключается.** Проверьте `warp-cli --accept-tos status`. Повторное «Применить настройки» перерегистрирует узел тем же токеном. Если узел удалён в Cloudflare — «Отключить от Mesh», затем «Подключить к Mesh».

**Цепочка не работает, но все узлы в сети.** Проверьте в разделе Cloudflare, что профиль устройств не перехватывает весь трафик и что в аккаунте включено *Allow all Cloudflare One traffic to reach enrolled devices*.

**Нужен доступ к серверу с закрытым публичным SSH.** С входного сервера: `ssh root@<Mesh-адрес>`. Либо включите «Публичный SSH» в карточке сервера и примените. При полной потере Mesh используйте консоль провайдера и выполните `nft delete table inet wdtt_router`.

**Забыт пароль панели.** `sudo wdtt-router reset-password` на входном сервере.

**Неудачное обновление.** Установщик сам возвращает прежнюю версию, если новая не запустилась. Вручную: `sudo bash install.sh rollback`.

## Полное удаление

1. В панели уберите серверы из цепочки, примените, удалите серверы (это удаляет с них все компоненты и Mesh-узлы в Cloudflare).
2. На входе: `sudo bash install.sh uninstall --purge`.
