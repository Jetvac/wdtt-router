# Безопасность

- HTTPS включён всегда. Первый сертификат самоподписан; сверяйте SHA-256 отпечаток через консоль VPS. Закройте порт панели внешним firewall для посторонних адресов.
- Пароли пользователей хешируются Argon2id. Сессия хранится в cookie `Secure`, `HttpOnly`, `SameSite=Strict`; изменяющие запросы требуют CSRF token. Неудачные попытки входа ограничены.
- Токены Cloudflare, ссылки VLESS, пароли WDTT и 3x-ui шифруются AES-GCM в SQLite. Ключ `master.key` хранится рядом с базой с правами root. Резервная копия базы без этого ключа не восстанавливает секреты.
- Секреты показываются только после входа по отдельному запросу. Просмотр фиксируется в аудите. Диагностический пакет не содержит токенов, ключей и паролей.
- Контроллер работает от root, и root SSH нужен для первичной установки агента. Проверьте отпечаток SSH сервера при подключении. Для 3x-ui используйте локальный SSH туннель.
- VLESS без TLS допускается здесь только внутри доверенного приватного Mesh. Не открывайте порт VLESS в Интернет. Firewall разрешает его лишь со стороны контейнерного Mesh адреса.
- Сетевые правила создаются в собственных цепочках `WDTT_PANEL_*`; существующие правила чужих приложений не удаляются. Независимый таймер восстанавливает предыдущее состояние при потере связи.
- Режим stealth блокирует только ICMP echo; ICMP ошибки, нужные для PMTU, не блокируются.
- Приложение удаляет события, аудит и завершённые задания старше 24 часов. Срок хранения системного `journald`, SQLite backups и логов WDTT/3x-ui управляется отдельно средствами ОС.

API token Cloudflare должен иметь только разрешения, необходимые для Mesh в выделенном аккаунте. Не храните его в shell history, репозитории или открытом документе. После завершения тестирования отзовите временные токены и смените пароли, которые были переданы в переписке.
